## Feature 1: Apple Watch Companion App

### Vision
Score matches directly from your wrist. Perfect for players who don't want to carry their phone courtside.

### User Stories

**As a tennis player, I want to:**
- Start a new match from my Apple Watch
- Score points with simple taps (no typing)
- See current score at a glance
- End match and sync to iPhone

**As someone who leaves their phone in their bag, I want to:**
- Use only my watch during matches
- Have match data sync automatically when I return to my phone

### Technical Approach

#### Architecture

**Watch App Structure:**
```
FirstServe Watch App/
├── Views/
│   ├── WatchMatchListView.swift       # List of active matches
│   ├── WatchNewMatchView.swift        # Quick match setup
│   ├── WatchLiveMatchView.swift       # Scoring interface
│   └── WatchMatchCompleteView.swift   # Summary
├── ViewModels/
│   └── WatchMatchViewModel.swift      # Watch-specific logic
└── Extensions/
    └── FSMatch+Watch.swift            # Watch helpers
```

**Shared Code (via Watch Connectivity):**
- `FSMatch` model (shared via SwiftData or synced struct)
- `MatchViewModel` logic (subset for watch)
- Color themes (court surfaces)

#### Watch UI Design

**WatchLiveMatchView:**
```
┌─────────────────────┐
│   John    vs   Jane │
│  HARD COURT        │
│                    │
│    [6]  [5]       │  ← Large, tappable score
│    [40] [30]      │
│                    │
│   🎾 John serving  │
│                    │
│  [Undo] [End]     │
└─────────────────────┘
```

**Key Interactions:**
- Tap player's score area to increment
- Digital Crown to undo last point
- Force Touch for match options (pause, end)

#### Sync Strategy

**Watch Connectivity Framework:**
- **Real-time sync** when iPhone is nearby
- **Background transfer** for completed matches
- **Conflict resolution:** iPhone is source of truth

**Data Flow:**
```
Watch initiates match → Sends to iPhone → iPhone creates FSMatch
Player scores on Watch → Updates sent to iPhone → UI refreshes
Match ends on Watch → Final data transferred → iPhone saves
```

#### Edge Cases

- **Watch app starts match, iPhone is off:** Queue match creation until iPhone is available
- **Both devices edit same match:** iPhone wins, Watch shows conflict alert
- **Watch battery dies mid-match:** iPhone has last known state
- **No iPhone nearby:** Watch stores match locally, syncs when reconnected

## Feature 2: Visual Share Cards

### Vision
When a player completes a match, generate a beautiful image card for sharing on social media. Think: Instagram-worthy match summaries.

### User Stories

**As a player who just won, I want to:**
- Share my victory with friends on social media
- Have a visually appealing card (not just text)
- Show final score + key stats + court surface

**As someone who posts to Instagram/Twitter, I want to:**
- One-tap share to social apps
- Card that matches FirstServe's premium aesthetic
- Option to hide opponent's name (privacy)

### Design Concept

**Visual Share Card Layout:**

│                                   │

**Design Elements:**

- Large, readable scores
- Minimal stats (aces, winners, duration)
- FirstServe branding (subtle)
- 1080×1080 square (Instagram-friendly)

### Technical Approach

#### SwiftUI Image Rendering

Use `ImageRenderer` to convert SwiftUI view to UIImage:

```swift
struct ShareCardView: View {
    let match: FSMatch
    
    var body: some View {
        ZStack {
            // Court surface gradient
            LinearGradient(...)
            
            VStack(spacing: 20) {
                // FirstServe logo
                // "HARD COURT VICTORY"
                // Score display
                // Quick stats
            }
        }
        .frame(width: 1080, height: 1080)
    }
}

func generateShareCard(for match: FSMatch) -> UIImage {
    let cardView = ShareCardView(match: match)
    let renderer = ImageRenderer(content: cardView)
    renderer.scale = 3.0 // Retina quality
    return renderer.uiImage ?? UIImage()
}
```

#### Share Sheet Integration

```swift

    let image = generateShareCard(for: match)
    let activityVC = UIActivityViewController(
        activityItems: [image],
        applicationActivities: nil
    )

}
```
