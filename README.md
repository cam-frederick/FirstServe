# MatchPoint

A simple, elegant tennis scoring and stats tracking app for iOS.

## Features

### MVP (Phase 1)
- Quick match start (opponent name + surface + best-of)
- Live scoring with undo
- Match history with search
- Basic stats (aces, double faults, winners, errors)
- iCloud sync

### Premium Features (Phase 2)
- Advanced stats (first serve %, break point conversion)
- Head-to-head records
- Trend graphs over time
- PDF match report export
- Apple Watch quick scoring

## Tech Stack
- SwiftUI
- SwiftData for local persistence
- CloudKit for iCloud sync
- StoreKit for subscriptions

## Monetization
- Free: Basic match logging
- Premium ($2.99/mo): Stats, trends, head-to-head, export
- Lifetime: $9.99
